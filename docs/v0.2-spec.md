# Scratchpad v0.2 behaviour spec

Source of truth for both apps. Design canvas: https://claude.ai/artifact/Lr6cgFti87ULk2zK8U9G8d
(boards: Desktop, Blocks, Popovers, Export, Motion). UI copy says "sheet"; code may keep `Pad` as the type name.

## 1. File format v2

One JSON file per sheet at `<root>/pads/<id>.json`, assets at `<root>/assets/<uuid>.<ext>`. Schema: `shared/schema/pad.schema.json` (v2).

- `v`: 2. `id`: `YYYY-MM-DD-xxxxxx` for dated sheets (date + 6 lowercase base36 chars), a slug for pinned sheets. Ids match `^[A-Za-z0-9_-]{1,80}$`.
- `date`: `YYYY-MM-DD` or null (pinned). Several sheets may share a date.
- `tags`: array of strings, lowercase, no `#`, no spaces, unique, in insertion order.
- Block adds: `rotation` (degrees, float, default 0), `font` (`sans` | `serif` | `mono` | `hand`, default `sans`), `fontSize` (int, default 14), `bold`, `italic` (bool, default false), `colWidths` (int px per column, tables only, optional). `h` is now honoured for every block kind after a corner resize; null means content height.
- Reading v1: `tag` (string) becomes `tags: [tag]` when non-empty; missing new fields take defaults; `id` stays as it was (a v1 id of `YYYY-MM-DD` is still valid). Always write v2.

## 2. Sheets

- **New sheet** (button, Ctrl/Cmd-N): always creates a sheet dated today, inheriting the current sheet's tags, and focuses its title. Split-button menu: New sheet today, New sheet on a date… (date picker), New pinned sheet, Duplicate this sheet (blocks and open to-dos copied, new ids, title + " copy").
- **Today on launch**: if no sheet is dated today, create one and carry over (section 4). If several exist, open the most recently updated.
- **Date picker** from the DATE box: month grid, Monday first, today ringed, a dot under days that already have sheets. Typed input accepted: `today`, `tomorrow`, `yesterday`, weekday names or 3-letter prefixes (next occurrence, today counts), `15 oct`, `oct 15`, `15/10`, `2026-10-15`, `+3`, `-2`. Choosing a date moves the sheet (its blocks and to-dos go with it). The id never changes, even though its date prefix no longer matches. Pinned sheets can be given a date, which unpins them.
- **Tags**: chips in the header, `×` removes, `+ tag` opens an input with suggestions (existing tags by prefix, with sheet counts) and "Create #x". Enter adds, Backspace in the empty input removes the last chip.
- **Sidebar**: segmented By day / By tag. By day: groups Today, Yesterday, weekday name (within 6 days), else `ddd d MMM`; newest first; group header shows short date. Rows show title (or "Untitled sheet") and first tag. By tag: one group per tag (a sheet appears under each of its tags), Untagged last; sort A to Z / Most sheets / Recently used (max updatedAt). Pinned section stays at the bottom.
- **Search** (Ctrl/Cmd-K) matches title, tags, id, block text, table cells, file names, URLs, captions, to-do text.

## 3. Blocks

- **Selection** shows a 1.5 px accent outline offset 5 px, four 10 px corner handles, and a floating toolbar above the block's top-left: Move grip, Font (family + size), Rotate (shows angle), Duplicate, divider, Delete (tinted, label "Delete").
- **Move** by dragging the 8 px edge band around the block, or the toolbar grip. Inner text stays editable. Snaps to the 24 px grid on release; Alt disables snap.
- **Resize** from the four corners, changing w and h (and x/y for left/top corners). Shift keeps aspect ratio. Min 48 × 24.
- **Rotate**: toolbar click adds 15°; dragging the rotate button rotates freely (angle from block centre to pointer); Shift snaps to 15°; double-click the angle resets to 0. Stored normalised to (-180, 180].
- **Delete**: toolbar button, or Delete/Backspace when the block is selected and no text inside it has focus. Undo toast "<Kind> deleted · Undo" for 8 s restores it at the same index.
- **Duplicate**: copy offset by +24, +24, selected.
- **Fonts**: Sans (IBM Plex Sans), Serif (IBM Plex Serif), Mono (IBM Plex Mono), Hand (Caveat). Size stepper 10–48. Bold, Italic. "Make sheet default" is out of scope for v0.2 (app default lives in Settings: Default font). Apple may map to system SF / New York / SF Mono / a bundled or system handwriting face.

## 4. Tables and formulas

- Column letters A, B, C… and row numbers 1, 2, 3… show only while the table is selected. A formula bar above the table shows the focused cell's address and raw content.
- **Column widths**: drag the boundary to the right of a column letter (min 40 px). Double-click fits the column to its longest content (approx 7.5 px per char + 20, clamp 40–480). Stored in `colWidths`.
- **Formulas**: a cell whose raw text starts with `=`. Grammar: numbers, cell refs (`A1`, case-insensitive), ranges (`A1:B3`) only inside functions, `+ - * /`, unary minus, parentheses, functions `SUM AVG AVERAGE MIN MAX COUNT` taking any mix of ranges, refs and expressions separated by `,`. Numbers in cells parse after stripping `,` thousands separators and surrounding whitespace; `£$€%` prefix/suffix ignored. Empty cells are 0 in arithmetic and skipped by functions. COUNT counts numeric cells.
- Errors shown in place of the value: `#REF!` (ref outside the table), `#DIV/0!`, `#CYCLE!` (self/circular reference), `#ERR!` (anything else). Results format with up to 4 decimals, trailing zeros trimmed, thousands separators for |x| ≥ 1000.
- Display shows the computed value right-aligned in mono; editing shows the raw formula.

## 5. To-dos

- Count reads "N of M done" and updates on every keystroke and status change. M counts non-empty rows.
- Column shows the sheet's rows plus exactly one blank row at the end (no more 18 fixed rows). Typing in the blank row creates a real row.
- Row: six-dot grip (drag handle), status circle (click cycles open, done, deferred), text input (underline, no box).
- **Sort** menu: Manual (drag), Open first, Overdue first, A to Z, Oldest first; checkbox "Done sinks to the bottom" (default on, applies to every mode including Manual). Sort is a view preference stored per device, not in the file. Dragging a row while a non-manual sort is active writes the current view order into the file, then switches to Manual.
- **Drag** by the grip: reorder within the column (insertion line), drop on the sheet canvas to turn it into a text block at that grid point (row removed), drop on a sheet row in the sidebar to move it to that sheet.
- Overdue = open, non-empty, createdAt ≥ 3 days ago: text in the overdue colour.
- Footer: "+ Add to-do" and "N open will carry to tomorrow" / "Nothing to carry. Nice." / "Nothing here yet".
- **Carry-over**: when today's first sheet is created, open and deferred non-empty rows from every sheet of the latest earlier dated day are copied as open (createdAt kept, carriedFrom = source sheet id). Done rows stay.

## 6. Export (one dialog, three modes)

- **Sheet as image**: PNG of the whole sheet (header, canvas bounding box, and optionally the to-do column), theme Light / Dark / Match app, scale 1x / 2x / 3x. No selection chrome. Copy (clipboard image) and Save.
- **To-dos as Markdown**: scope This sheet / All of today's sheets / Every open to-do; checkboxes Include done (default off), Include deferred (default on). Format below. Copy and Save `.md`.
- **Everything, one file**: format Scratchpad archive `.scratchpad` / Markdown `.md` / JSON `.json`; scope All sheets / One tag. Save only.

To-do Markdown (one section per sheet, sheets newest first, blank line between sections):
```
## <title or "Untitled sheet">, <ddd d MMM yyyy | "Pinned">

- [ ] Open item
- [x] Done item
- [ ] Deferred item (deferred)
```
Every-open-to-do scope includes only open rows (deferred if ticked) and omits empty sections.

Archive `.scratchpad` (JSON, UTF-8):
```
{ "format": "scratchpad-archive", "v": 1, "exportedAt": "<ISO>", "sheets": [<sheet v2>...], "assets": { "assets/<file>": "<base64>" } }
```
Import (menu: Import archive…) merges: sheets with an existing id are overwritten, assets written if missing.

Markdown everything: per sheet `# <title>` then `_<date or Pinned> · #tag #tag_`, then blocks in reading order (y then x): text as paragraphs, code fenced, tables as GFM tables with computed values, images `![caption](assets/…)`, files `[name](assets/…)`, links `[title](url)`, dividers `---`; then `## To-do` with the checkbox list.

## 7. Motion and whimsy

Setting **Whimsy**: Full (default) / Subtle / Off. System reduce-motion forces Off. Animations never block input.

| Moment | Full | Subtle |
|---|---|---|
| Tick a to-do | circle pop scale 1 → 1.3 → 0.9 → 1, 460 ms spring; tick stroke draws 260 ms after 90 ms; strike line scales in from left 300 ms after 140 ms; 6 ink flecks fly 18–24 px and fade, 560 ms | pop 260 ms, no flecks |
| Count changes | rises 4 px and settles, 360 ms spring | same |
| Last open to-do ticked | "ALL CLEAR" rubber stamp (double border, overdue colour, -8°) drops from scale 1.9 rotated -16°, 520 ms spring; column 2 px thud. Once per sheet per day | fades in 300 ms |
| New sheet | old sheet peels up and away from top-right (translate -60 px, -110 %, rotate -9°, fade) 680 ms ease-in; new sheet rises 6 px and fades in, 420 ms after 120 ms; empty sheet draws a pencil squiggle 1.4 s after 0.5 s, then the hint text fades in | peel 360 ms, no squiggle |
| Paste / insert | block falls 16 px, overshoots 3 px, settles, 280 ms spring; dotted ripple ring under it, 520 ms | no ripple |
| Drag a block | lifts 5 px, tilts 2° opposite travel, shadow deepens, 180 ms; on drop snaps and bounces once, 240 ms | lift without tilt |
| Delete block | scales to 0.5, rotates 10°, drops 14 px, fades, 300 ms ease-in; undo toast rises 12 px | fade 200 ms |
| Carry-over | carried rows hop in on a small arc, 420 ms, 90 ms stagger | slide, no arc |
| Menus, date picker, dialog | scale 0.94 → 1 and fade from the opener, 140 ms ease-out | fade |
| Theme switch | sun rotates 90° and shrinks out, moon rotates in; paper colours cross-fade 360 ms | cross-fade |
| Hover a block | lifts 3 px with shadow, 180 ms spring | none |
| Hover a grip | grip wiggles ±12°, 360 ms | none |

Off: every change is instant.
